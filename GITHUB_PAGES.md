# GitHub Pages deployment

1. Put the contents of this project at the root of the GitHub repository.
2. Push the project to the `main` branch.
3. In GitHub: Settings -> Pages -> Build and deployment -> Source -> GitHub Actions.
4. Open the Actions tab and wait for `Deploy Cybertec to GitHub Pages` to finish successfully.
5. The project site URL will be:
   https://<your-github-username>.github.io/Cybertec-Web-Application/

This project uses Vite + React + React Router and is configured for the repository path
`/Cybertec-Web-Application/`.
